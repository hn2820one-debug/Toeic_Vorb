## 3. Today（今日儀表板）

### 功能說明

- **Next Action（下一步動作）**：可點擊，直接跳到推薦課程或複習佇列。
- **Due Reviews（待複習數量）**：顯示今日到期的複習題數。
- **Stage Seal Readiness（階段封印就緒度）**：顯示各階段的精熟進度（純顯示，不鎖定功能）。`無資料` 代表缺少課程或作答資料；`未達標` 代表已有資料但尚未達到封關條件。
- **V0 Diagnostic Recommendation（V0 診斷建議）**：累積至少 20 次 V0 作答後，根據答題結果顯示建議學習路徑；1–19 次時只顯示資料不足。

### 使用方式

1. 每次學習前先看 Today 頁確認推薦行動。
2. 乾淨 reseed 時 **Next Action** 會先指向 `V2-A-71`；之後會自動跳到下一個未完成正式課。
3. 如果未來 **Next Action** 再次顯示正式課程重建中，請先進入 Roadmap 或 Question Bank 檢查本機資料；規劃細節仍以 repo 內的 `docs/Future Plan.md` 為準。
4. 若待複習數量 > 0，優先完成複習再開新課。
5. **進階工具** 區塊提供 **匯出完整資料封包** 與 **題庫管理**；這兩項屬於備份 / 維護用途，不是一般學習主流程。

### 功能說明

- 列出所有階段（V0–V3）的課程，顯示狀態（未開始 / 進行中 / 完成）。

### 使用方式

1. 有正式課程時，點擊課程列的 **Start** 或 **Continue** 按鈕開始課程。
2. 使用篩選器縮小顯示範圍，例如只看「V3 / 進行中」。
3. 已完成課程顯示綠色打勾；進行中顯示進度條。
4. Roadmap 下方的 **進階工具** 會固定提供 **匯出完整資料封包** 與 **題庫管理**，方便在排程之外進行備份或檢查。

## 5. Lesson（課程執行）

目前正式 seed 已有 `V2-A-71` 到 `V2-A-80`、`V2-MR-01` / `V2-MR-02`、`V3-A-121` 到 `V3-A-143`、`V3-MR-01`–`V3-MR-04` 可開始。若未來 seed 又回到空狀態，Lesson 頁才會顯示「正式課程重建中」與 Roadmap / 匯出 / 題庫管理入口。以下流程適用於目前正式課程與測試 fixture 模式。

### 課程流程

```
選擇答案 → 點擊「Confirm Answer」 → 查看回饋 → 點擊「Next Question」 → 重複到課程結束
```

### 答題介面

- 每題顯示**題目**、**填空句**（部分題型）、以及 **A / B / C / D 四個選項**。
- 計時器顯示剩餘作答時間（依題型：8–45 秒不等）。
- **必須點擊「Confirm Answer」才會儲存答題記錄**，直接點選選項不會儲存。

### 回饋畫面

每題確認後顯示：

| 資訊 | 說明 |
|------|------|
| 正確 / 錯誤 | 本題結果 |
| 正確答案 | 標準答案 |
| 你的選擇 | 你選的答案 |
| 解析 | 說明正確答案的原因 |
| 目標詞彙 | 本題目標詞彙 |
| 中文意思 | 目標詞彙中文翻譯 |
| 例句 | 目標詞彙範例句 |
| 文法 / 搭配 | 相關文法或搭配說明（若有） |

### 不熟單字標記

做題時可用滑鼠選取題幹或選項中的英文單字或短片語。系統會把它記錄為「不熟單字」，在本題下方即時顯示，並在 Export 中輸出 `word_highlights` 與 `word_highlight_summary` 檔案。

### 課程類型說明

| 類型 | 作答方式 | 時限 |
|------|----------|------|
| meaning_choice | 選擇詞彙意思 | 10 秒 |
| scene_vocabulary | 填入場景詞彙 | 15 秒 |
| word_family | 選正確詞性形式 | 20 秒 |
| collocation | 填入正確搭配動詞/名詞 | 15 秒 |
| part5_sentence_completion | Part 5 句子填空 | 20 秒 |
| part6_context_choice | Part 6 段落填空 | 45 秒 |
| speed_drill | 高速反射填空 | 8 秒 |
| review_question | 複習題（混合格式） | 15 秒 |

### 超時處理

- 時間到自動算錯，系統仍會顯示正確答案的回饋畫面。
- 超時答錯的詞彙會加入複習佇列。

## 6. Mistakes（錯題與複習佇列）

### 功能說明

- 顯示近期答錯的題目，以及待複習佇列中的詞彙。
- 可執行 **Review Mode（複習模式）** 處理到期 / 高優先 / 反覆出錯的項目。

### 複習結果標記

每題複習後選擇：

| 標記 | 意思 |
|------|------|
| Fixed | 已理解，不再需要立即複習 |
| Still Weak | 仍需複習，安排 1–2 天後再出現 |
| Repeated Error | 反覆答錯，立即加入高優先佇列 |

### 建議使用方式

1. 每次學習前先完成 Today 頁顯示的待複習項目。
2. 在 Mistakes 頁查看哪些詞彙反覆出錯，重點加強。

## 7. Mastery（精熟度總覽）

### 精熟等級

| 等級 | 分數範圍 | 說明 |
|------|----------|------|
| blind | 0–39 | 從未見過或總是答錯 |
| weak | 40–59 | 見過但不穩定 |
| unstable | 60–74 | 常答對但不一致 |
| stable | 75–84 | 可靠，偶有錯誤 |
| mastered | 85–100 | 快速且一致正確 |

### 計分公式

```
分數 = 答對率(50%) + 答題速度(25%) + 穩定度(15%) + 近期表現(10%)
```

### 使用方式

- 使用篩選器依精熟等級查看詞彙（例如只看 `weak` 或 `blind`）。
- 點擊詞彙項目查看詳細資訊：中文意思、例句、歷史答題記錄。

## 8. Export（匯出資料）

### 匯出內容

| 檔案 | 說明 |
|------|------|
| CSV | 詞彙學習記錄（可用 Excel 開啟） |
| JSON | 完整資料快照（可用於備份） |
| Markdown | 摘要報告（可直接閱讀） |
| JSONL | 逐行 JSON（供 AI 分析使用） |
| review_effectiveness | 複習效果分析 |
| content_quality_summary | 題目品質摘要 |
| stage_progress | 各階段進度 |
| diagnostic_recommendation | V0 診斷建議；少於 20 次 V0 作答時標示 `insufficient_data` |
| word_highlights | 做題時手動標記的不熟英文單字 |
| word_highlight_summary | 不熟單字彙總與出現次數 |
| Google Drive 備份檔 | 單一 `toeic_vocab_backup_YYYY-MM-DD.json`，供手動搬到 Google Drive |

### 使用方式

1. 點擊 **Export** 分頁。
2. 點擊 **匯出完整資料封包**。
3. 若瀏覽器支援資料夾選取，檔案會直接整理成資料夾；若不支援，會改為逐一下載，且此靜態版本不支援 zip。
4. 若要跨平台延續紀錄，點擊 **匯出 Google Drive 備份檔**，取得單一 `toeic_vocab_backup_YYYY-MM-DD.json`，再自行上傳或移到 Google Drive。
5. 在另一台裝置上，先從 Google Drive 下載該 JSON，再於 Export 點 **匯入備份檔**。系統會先 preview，確認後才執行 safe merge。
6. Safe merge 只合併學習紀錄；相同 ID 不重複匯入，本機設定優先，production 題庫 / 課程來源 JSON 與 seed version 不會被備份檔覆蓋。
7. Google Drive 在這裡只是手動保存位置，不是即時雲端同步；App 目前不登入 Google、不串 Drive API。真正 Google Drive 同步已另行記錄為 `SYNC-01`，見 `docs/google-drive-cloud-sync-plan.md`，但尚未實作。
8. 在執行 **Reset All Data**、清除瀏覽器資料、或切換瀏覽器前，請先匯出備份；IndexedDB 不是永久雲端保存。

## 9. Question Bank（題庫管理）

### 功能說明

- **搜尋**：依關鍵字搜尋題目。
- **分頁**：分頁瀏覽所有題目。
- **本地編輯**：在瀏覽器內直接修改題目內容（儲存至 IndexedDB，不修改原始 JSON）。
- **匯入**：匯入外部 JSON 題目。
- **Patch 匯出**：將本地編輯的差異匯出為 patch 檔，供後續合併回原始 JSON。

### 重要說明

> 在瀏覽器內編輯題目**只會修改 IndexedDB**，不會直接更新 `data/vocab/` 下的原始 JSON 檔案。
> 如需永久更新原始題庫，請使用 `scripts/apply-questionbank-patch.js` 腳本合併 patch 檔。

### Patch 工作流程

```
在瀏覽器編輯題目
→ 點擊「Export Edits as Patch」
→ 儲存 patch 檔
→ node scripts/apply-questionbank-patch.js <patch 檔>
→ 確認原始 JSON 已更新
```

## 12. 常見問題

**Q：課程列表是空的，沒有課程可以選？**
A：目前正式 production seed 已上線 39 堂 lessons（V2 12 堂、V3 27 堂）。如果你仍看到空列表，請先清除 Service Worker 快取並重整頁面，或確認瀏覽器 IndexedDB 已依新 seed 重新建立。

**Q：為什麼之前要先清空正式題庫？**
A：舊題庫在語意洩漏、重複題幹、題型規則與教學策略上需要重新治理。先清空 production seed 可以避免學生繼續練到不合規格的題目，也讓重建 wave 能以新標準重新上線。目前 `V2-A-71` 到 `V2-A-80` 已作為 wave 1 + wave 2 + wave 3 + wave 4 恢復，`V2-MR-01` 也已作為第一個混合複習 checkpoint 上線。

**Q：那現在可以做什麼？**
A：可以直接開始 `V2-A-71` 到 `V2-A-80`、`V2-MR-01` / `V2-MR-02`、`V3-A-121` 到 `V3-A-143` 與 `V3-MR-01`–`V3-MR-04`，查看 632 個詞彙項目、使用 Question Bank 的本機工具、匯出既有 IndexedDB 學習資料，並依 `docs/Future Plan.md` 追蹤下一波重建任務。

**Q：答題記錄不見了？**
A：學習資料存在 IndexedDB，若瀏覽器資料被清除則資料會遺失。請定期使用 Export 的 **匯出 Google Drive 備份檔** 產生 JSON，並自行放到 Google Drive。這目前不是即時同步；還原時需先下載檔案再匯入 preview / safe merge。真正 Google Drive 同步已規劃為 `SYNC-01`，但尚未實作。

**Q：修改了題目但重新整理後沒變化？**
A：在 Question Bank 的編輯只寫入 IndexedDB，不影響原始 JSON。如需永久保存，請使用 patch 匯出工作流程（見第 9 節）。

**Q：計時器到了但我還沒選答案怎麼辦？**
A：超時自動算錯，系統會顯示正確答案的回饋。該詞彙會加入複習佇列，之後會再次出現。

**Q：如何重設所有資料重新開始？**
A：在 Settings 頁點擊 **Reset All Data**。注意這會清除所有學習記錄，請先匯出備份。
