TOEIC Vocabulary Tracker

這是單字學習程式的入口。你只需要按按鈕，不需要懂程式設定、資料庫或檔案結構。

開始學習 / 開啟主程式 如果畫面怪怪的，先清除快取
1. 開啟主程式 按「開始學習」進入內容頁面。
2. 點 Lesson / Review 一般上課按 Lesson；要複習錯題按 Mistakes。
3. 如果看見舊畫面 先按「清除快取」，再回來重新開啟。

你需要知道的只有這些

  • 這個程式是獨立的，不會改到 Grammar / PoS App。
  • 學習資料已經預先放好，直接打開就能用。
  • 如果資料更新後沒有看到新內容，先清除快取。
目前內容：V0 + V1 + V2 + V3，共 202 lessons / 4,608 questions（含 22 個混合複習課）
本機資料位置：data/vocab/*
儲存位置：toeic_vocab_tracker_db

平日使用

  • 先開主程式。
  • 按 Lesson 開始上課。
  • 答題後直接按下一題。

複習使用

  • 按 Mistakes 查看錯題。
  • 按 Review Mode 開始複習。
  • 複習完按 Finish Review。

維護使用

  • 更新後看不到新內容時，先清除快取。
  • 如果瀏覽器舊資料卡住，重新開頁面。
  • 不需要手動改檔案。
如果你只想最快開始：按「開始學習 / 開啟主程式」即可。
如需清除 Service Worker 快取，請開啟 清除快取頁面。
